# QB HOUSE 混雑観測所（非公式）

## スマホから公開する手順
1. GitHubで新しいPublic repositoryを作る。
2. このZIPを展開し、中身をリポジトリへアップロードする（`.github` フォルダも含む）。
3. Settings → Pages → Build and deployment → Source を `Deploy from a branch` にする。
4. Branchを `main`、フォルダを `/ (root)` にしてSave。
5. Actionsタブで `Update QB HOUSE data` を一度手動実行する。
6. 数分後、GitHub PagesのURLを開く。

5分ごとにデータ更新を試みます。QB HOUSE側のHTML変更・アクセス制限等で停止する可能性があります。
公開前に、取得頻度や利用条件を確認し、過度なアクセスを避けてください。
